🛡️ Vulnerability Analysis & Secure Remediation

❌ Why This Code Is Vulnerable

The application concatenates raw strings into SQL commands without parameterization:

// VULNERABLE PATTERN
const sql = `SELECT * FROM users WHERE username = '${username}' AND password = '${password}'`;
db.get(sql, ...);

When the input contains single quotes, the SQL parser is tricked into treating user input as syntax tokens, breaking the query boundaries.

✅ How To Fix (Secure Parameterization)

Always use parameterized prepared statements with positional placeholders (?):

// SECURE REMEDIATION
const sql = 'SELECT * FROM users WHERE username = ? AND password = ?';
db.get(sql, [username, password], (err, user) => { ... });

With parameterization, the database engine treats all input strictly as literal strings, preventing query manipulation entirely.
