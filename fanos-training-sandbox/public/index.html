FANOS SEC — SECURITY TRAINING SANDBOX

An interactive, isolated cybersecurity proving ground powered by Node.js, Express, and an in-memory SQLite database. Learn how critical web application vulnerabilities work, practice exploitation techniques, and master defensive secure coding standards.

🛡️ Sandbox Architecture & Environmental Isolation

1. In-Memory Database

All lab state resides purely in SQLite RAM (:memory:). Restarting the Node server resets all tables and seed records to clean initial states.

2. Live Query Telemetry

Each lab module provides real-time backend query inspectors so students can see exactly how their inputs manipulate backend logic.

3. Dual-Sided Education

Every lab contains both the offensive exploitation vectors and the corresponding defensive remediation code (Parameterized queries & CSP).
