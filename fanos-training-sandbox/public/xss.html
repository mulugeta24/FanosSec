🛡️ Vulnerability Analysis & Secure Remediation

❌ Why This Code Is Vulnerable

The frontend takes raw user input from the API and inserts it directly into the DOM using innerHTML:

// VULNERABLE DOM INSERTION
messageDiv.innerHTML = comment.message;

The browser parses the string as HTML tags and event handlers (e.g. onerror), executing unauthorized script logic in the victim's session.

✅ How To Fix (Context-Aware Escaping & CSP)

1. Use safe DOM text assignment (textContent):

// SECURE DOM INSERTION
messageDiv.textContent = comment.message;

2. For rich text, sanitize with DOMPurify.sanitize(input).
3. Set HttpOnly on sensitive cookies to block JavaScript extraction.
